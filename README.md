# Multiplica Aventura Plus 🦊
Web app educativa para practicar tablas, con progreso local, niveles, estrellas, audio sintetizado y práctica de errores.

## Abrir y probar
Descomprimí y abrí index.html en el navegador.

## Publicar en Vercel (sin programar)
1. Creá una cuenta gratuita en https://vercel.com
2. Para la forma más simple de publicar, usá https://vercel.com/new y conectá un repositorio GitHub con estos archivos.
3. Seleccioná Other como framework, sin build command, Output Directory `.`.
4. Deploy. La app no necesita backend.

La aplicación guarda el progreso localmente en el navegador. El audio se genera en el navegador y no descarga archivos.
